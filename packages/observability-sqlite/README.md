# @web-agent/observability-sqlite

A SQLite trace driver and reader for the `@web-agent/core` observability contract, used by the
Tauri desktop host. Depends on `@web-agent/observability-idb`.

This package is part of the [Einfach Agent](https://github.com/allroad88888888/einfach-agent)
workspace — see the main repository for setup, documentation and contribution guidelines.

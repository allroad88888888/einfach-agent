## 已实际观察的结果

1. 打开 `http://127.0.0.1:4178/fixture.html?scenario=history&width=360`，选择预置表单助手会话。真实 sendMessage 模拟响应生成三轮：第一轮读取页面、第二轮核对字段、第三轮给出建议。
2. AX 在每条用户记录下分别暴露撤销按钮（当时索引33/41/46），标题说明只影响对话、不能回滚外部操作；底部不再有全局会话操作栏。
3. 实点第二条消息下的撤销：第一轮用户消息及原回复仍在；第二、三轮均变为原位置的“你 · 已撤销”占位，其下各有“恢复至本轮”。AX 对应75/78，截图可见两个就地恢复入口。消息占主体高度、输入框固定底部、运行详情保持折叠，无横向溢出。
4. 原始截图保留在本轮 CUA `实点第二轮撤销并查看窄屏占位` 输出，未伪造本地PNG。截图发现整个占位 opacity 导致可用恢复按钮太浅，交240修复；最终改用muted正文、灰底和虚线，按钮保留正常对比，代码及最终构建已核。

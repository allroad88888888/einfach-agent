# 430 会话历史导航（2026-09-21，完成）

## 交互与实现

- 历史从设置移到对话顶部，替代原来的会话下拉框。历史列表临时占用聊天区域，返回或 Escape 回到对话，不常驻挤压聊天宽度。
- 列表按最近活动排序并按日期分组；支持标题 / Agent 搜索、当前标记、草稿标记。顶栏始终保留新建入口。
- 打开历史保留已挂载对话，切换复用 core 的 activeSessionId；运行不会因导航停止。各会话草稿在同一视图生命周期内分别保留，切换 client 时清理。
- 会话行的次级操作提供重命名、删除；列表管理菜单提供清空。删除前明确确认对象及数量；只删除确认时捕获的 ID，后创建的会话不被包含。删除当前会话由 core 选择其余会话，全空时显示新建入口。
- 新会话不再指定 Agent 名作为标题，直接复用 core 首条消息自动命名。旧标题不静默迁移，可手动重命名。
- 新增 HistoryView / HistoryAction；Conversation 从 ChatView 按职责抽出。没有增加运行包、持久化存储或跨包 UI 依赖。
- 修复回归测试发现的持久化问题：core.renameSession 同步写入恢复快照，避免重启时恢复权威元数据把用户改名覆盖。

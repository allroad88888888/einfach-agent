# 可选视图包展示 Agent 配置和完整对话状态

## 目标与交付边界

`@einfach-agent/browser-agent-ui` 提供默认配置与对话界面，消费外部创建的 client；独立于 Chrome 和实际站点。
所有表单、列表、对话和样式留在本包，持久配置与命令在 agent 包；包括交互、组件测试、样式和接入说明。
客户可以完全不安装本包，不能把逻辑藏进只能通过 React 调用的 hook。

## 上下文与覆盖

- 消费 index 的 BrowserAgentClient；下游派发前 010 的真实命令签名必须已同步入 index。
- 复用 `packages/agent-react/src/coreStoreBindings.tsx` 的 RootStoreProvider/AgentStoreProvider/只读 hooks。
- 复用 `@einfach-agent/core/timeline` 投影、实例 sessionAtomScope；禁止 deep import apps/web 的 settings/uiStore/defaultCore。
- 老 UI 可只读参考布局与 pending/recovery 语义，不复制其产品单例和依赖整棵 AppShell。
- 覆盖 C08、C09、C10；050 负责挂载到真实侧栏及客户示例。

## 接口

```ts
interface BrowserAgentViewProps {
  client: BrowserAgentClient;
  className?: string;
}
function BrowserAgentView(props: BrowserAgentViewProps): React.JSX.Element;
```

包根导出主视图与类型，样式从 `@einfach-agent/browser-agent-ui/styles.css` 显式引入。
组件可以组合本包内部 AgentSettings、SkillEditor、ConnectionSettings、ChatView；不额外拆 UI 子包。
挂载不创建/销毁 client，不用全局 Provider fallback；卸载只释放自身订阅。

## 行为要求

1. Agent 列表与创建/编辑/删除；选择模型连接、模型、工具和 Skills；instructions 可编辑。
2. Skill 列表、正文与文本资源编辑；配置版本与已有会话绑定关系可理解；不伪装可运行脚本编辑器。
3. 连接 endpoint/model/API key 表单；密码输入提交后清理，不回填明文 key，显示配置成功/失败与 configured 状态。
4. 按 Agent 新建与切换会话，消息流、工具进度/结果、输入框、停止、确认/拒绝、错误、恢复入口、对话 undo/redo。
5. 非当前视图会话继续产生状态时不窜入当前对话；所有命令使用所显示 session 的显式 ID。
   首版不展示计划执行、逐条历史编辑或其他本任务未消费的命令；不要求顺带改造这些旧产品路径。
6. 覆盖初始空态、加载失败、保存失败、无可用模型、缺失 Skill/tool、运行中、等待确认、恢复阻断与已取消状态。
7. 配置快照只读；表单草稿、焦点、面板展开等本地 UI 状态可在组件内。网络/持久化不能从组件直接调用。
8. 窄侧栏约 360px 与嵌入宽区域都可使用；键盘可完成操作、错误有文本、焦点不丢失。
   样式用包级范围，不覆盖宿主 body/button/input，不把扩展生命周期或工程术语塞进产品文案。
9. 复用项目现有本地化方式时只在本包维护资源，不修改旧 Web catalogs；至少中文默认文案完整。

## 验收标准

1. `pnpm exec vitest run browser-agent/ui`：使用真实 client + fake IndexedDB/mock fetch，完成配置→建会话→发送→工具结果。
2. 两个 client 对应两个同时挂载视图，配置/会话选择互不影响；保存失败不错误更新显示，卸载不停止另一视图 client。
3. 发送/停止/确认/恢复/undo 逐项验证命令作用于显示的 session；外部写入不可撤销提示与 core 状态一致。
4. `pnpm --filter @einfach-agent/browser-agent-ui build` 通过；包无 Chrome API 或 apps/web 私有导入。
5. 浏览器 fixture 截图覆盖空态、配置表单、运行/等待状态及窄宽两种尺寸；键盘焦点冒烟写入报告。
6. README 展示 client 外部创建、视图挂载/卸载、样式显式加载；不宣称客户必须采用本 UI。

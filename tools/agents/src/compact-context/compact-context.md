# compact_context

由运行时在上下文超预算时自动调用，执行顺序为 preCompact → compact → postCompact。
不接受模型参数，不出现在模型工具清单中。

工具通过当前 Agent 专属能力生成摘要，保留任务目标、约束、结论、进度和下一步。
运行时验证摘要、来源上下文和请求预算后提交状态；原始对话继续由现有历史机制保留。
主会话摘要沿用会话 writer、undo 和恢复快照。子 Agent 摘要只更新该子循环的上下文。
主会话恢复时，未完成且无回执的压缩调用可安全重试；已保存的有效摘要直接复用。
该恢复规则仅用于 compact_context，不改变 preCompact/postCompact 等其他工具的恢复检查。

返回覆盖条目数、原始 token 估算及摘要字符数，不重复返回摘要正文。
生成或提交失败时不写入新摘要，也不继续发送超预算请求。

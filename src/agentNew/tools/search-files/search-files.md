# search_files

在 workspace 内搜索文本文件中的字符串。

## 参数
- `query`（必填）：要查找的非空字符串。
- `path`（可选）：搜索起点，默认 `.`；可以是文件或目录。
- `glob`（可选）：简单文件过滤，支持后缀如 `*.ts` / `.md`，或普通子串匹配。
- `maxMatches`（可选）：最多返回匹配数，默认 `100`，最大 `1000`。

## 返回
- `matches`：匹配数组，每项包含 `path`、`line`、`lineNumber`。
- `truncated`：是否因为匹配上限或文件读取上限被截断。

## 注意
- 路径限制在 workspace root 内，逃逸路径会失败。
- 搜索使用普通字符串包含匹配，不支持正则。
- 二进制或非 UTF-8 文件会被跳过。

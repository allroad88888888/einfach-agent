# shell_linux

在本机 Linux shell 中执行用户请求相关的非交互命令。

## 参数
- `command`（必填）：要执行的命令，必须是非空字符串。
- `cwd`（可选）：命令工作目录；省略时默认使用当前会话设置的 workspaceRoot。
- `timeoutMs`（可选）：超时时间，默认 `30000`，最大 `120000`。
- `maxOutputChars`（可选）：最大输出字符数，默认 `20000`，最大 `100000`。
- `env`（可选）：额外环境变量，只接受 string:string。

## 使用准则
- 只执行与当前用户请求直接相关的非交互命令。
- 避免破坏性命令，例如删除、覆盖、重置、杀进程、改权限、清空目录等；确需执行时先向用户说明风险并取得明确确认。
- 需要长时间运行、持续监听、全屏 UI、密码输入或其他交互式命令时，先说明工具限制，并改用短命令、只读检查或让用户手动执行。
- 输出可能被 `maxOutputChars` 截断；需要更多上下文时分段执行更具体的命令。
